✨ 주요 기능

🖼️ 씬 간 img2img 참조
**이미지 참조**: scene_01-A 지시어로 앞 씬 이미지를 참조 이미지로 사용 → 캐릭터 일관성 확보. FAL Flux img2img 엔드포인트 자동 전환.
📡 SSE 실시간 스트리밍
파이프라인 각 단계의 진행 로그를 Server-Sent Events로 브라우저에 실시간 전달. 이미지 생성 완료 시 미리보기 즉시 노출.
💰 비용 추적
이미지·영상 생성 시 예상 비용 계산 및 cost-log.json 기록. 이미 생성된 씬은 자동 건너뜀.
✏️ sharp 텍스트 합성
**텍스트 합성** 지시어로 생성된 이미지 위에 한글 자막 오버레이. 폰트 크기 자동 조정, 외곽선 렌더링.
📐 비율 선택
프로젝트별 16:9 (1920×1080) / 9:16 (1080×1920) 선택 → 이미지·영상 생성에 자동 적용. 숏츠 최적화 지원.
🤖 Claude CLI Subprocess
모든 LLM 호출은 SDK 없이 claude CLI를 자식 프로세스로 spawn. ANTHROPIC_API_KEY 불필요, CLI 자체 인증 사용.
🎬 CapCut 자동 편집
영상 클립 + TTS 오디오 + 자막을 CapCut 프로젝트 JSON으로 자동 조립. 임포트 후 익스포트만 하면 완성.
🔁 에러 복구
project.lastStatus에 에러 직전 상태 기록 → 복구 API가 해당 단계부터 재시작. start-images는 error 상태에서 자동 복구.
